# Provenire Agents

Многоагентна система за интелигентна оценка на доставчици в автомобилната
индустрия. Настолно приложение за Windows, в което екип от специализирани
агенти се консултира помежду си, а отделен агент-критик оспорва изводите им.

## Съставът на агентите

| Агент | Роля |
|---|---|
| **Оркестратор** | Управлява цикъла консултация → критика → преработка |
| **Учен** | Търси и чете научни статии, осъществява надзор над методологията и предлага нови подходи |
| **Данни** | Събира и валидира входните данни; следи за липси и аномалии |
| **Оценка** | Прилага модела AISIM: CSS, FAIS, класификация |
| **Риск** | Прогнозен риск, тенденции и ранни предупреждения |
| **Критик** | Оспорва анализа, проверява допусканията и коректността на цитатите |
| **Съответствие** | Контролен пункт: сканира за чувствителни данни и блокира препоръката при риск от изтичане |
| **Препоръка** | Синтезира валидирания анализ в действено решение |

### Ролята на агента „Учен"

Освен литературен обзор с проверени цитати, той изпълнява **научен надзор**
над самата разработка: проверява дали теглата са нормирани, дали коефициентът
α е в допустими граници, дали извадката позволява статистическо обобщение и
дали прогнозният компонент е емпирично обоснован. Въз основа на литературата
**предлага нови подходи** за решаване (хибриден MCDM + машинно обучение,
приносен анализ за обяснимост, анализ на чувствителността, многостепенна
видимост, оценка коригирана спрямо риска).

### Ролята на агента „Съответствие"

Той не е пасивен наблюдател, а действащ контролен пункт. Участва във **всеки
кръг** от консултацията, сканира резултатите на останалите агенти за
чувствително съдържание (структура на себестойността, марж, оферти,
техническа документация) и оценява риска спрямо избрания режим на работа.

При установено нарушение Критикът повдига **блокиращо** възражение, а агентът
„Препоръка" **задържа** отговора вместо да го издаде:

> „Препоръката е задържана от агента за съответствие: обработката би извела
> чувствителна информация извън средата. Необходимо е преминаване към локален
> режим или анонимизиране на данните."

Така политиката за поверителност е технически наложена, а не само декларирана.

## Модел AISIM

```
CSS  = 0,25·Q + 0,20·D + 0,20·C + 0,20·R + 0,10·S + 0,05·I
FAIS = α·CSS + (1 − α)·PSS,   α = 0,60
```

Шест измерения: качество, доставка, цена, риск, устойчивост, иновации.

## Консултативен цикъл

Специалистите изготвят анализ → Критикът повдига възражения → специалистите
преработват → цикълът се повтаря, докато не останат съществени възражения
(максимум три кръга). Окончателното решение остава за специалиста
(**Human-in-the-Loop**).

## Стартиране

```bash
python run.py
```

Приложението използва само стандартната библиотека (tkinter) и работи без
интернет. Езиковият модел е по избор:

- `offline` — детерминистичен режим, без модел (по подразбиране)
- `local` — локален модел през Ollama (on-premise, за поверителност)
- `cloud` — външен интерфейс; агентът „Съответствие" блокира чувствителни данни

## Сглобяване на Windows приложение (.exe)

```bash
build_exe.bat
```

Резултатът е `dist\Provenire.exe` — самостоятелен файл, който не изисква
инсталиран Python.
